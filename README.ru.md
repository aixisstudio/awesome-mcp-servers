Каталог MCP-серверов

###Что такое MCP?

**Модельный контекстный протокол** (Anthropic, открытый стандарт) — USB-C инструментария ИИ: один протокол, который позволяет любому LLM-клиенту общаться с любым источником инструментов/данных. Сервер MCP разоблачает **инструменты**, **ресурсы** и **подсказки**; клиент (Claude Desktop, Cursor, ваш агент) вызывает их.

## )️ Напишите свои собственные (10 строк)

```python
# python-sdk example
from mcp.server.fastmcp import FastMCP
mcp = FastMCP("my-server")

@mcp.tool()
def hello(name: str) -> str:
    return f"Hello {name}"

mcp.run()
```

Зарегистрируйтесь в Claude Desktop: `claude_desktop_config.json` → `mcpServers`.

##  notes Заметки безопасности

- Серверы MCP запускают ** местный код** - аудит перед установкой
Предпочтение доступа к файловой системе через `/`
- Описания инструментов можно вводить быстро - относиться к выходу сервера как к ненадежному
